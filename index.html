الاتصال بـ GitHub

يُحفظ التوكن في متصفحك فقط (localStorage) ولا يُرسل لأي جهة غير GitHub مباشرة. أنشئ التوكن من: Settings → Developer settings → Personal access tokens (fine-grained) مع صلاحية Contents: Read and write على هذا المستودع فقط.

تهيئة المستودع

إذا كان المستودع فارغًا أو ناقص، هذا الزر ينشئ الملفات الخمسة المطلوبة (apps.json, banners.json, categories.json, sources.json, settings.json) بقيم افتراضية فارغة وصحيحة، بدون التأثير على أي ملف موجود مسبقًا.
